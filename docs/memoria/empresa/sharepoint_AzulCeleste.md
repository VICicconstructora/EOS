# Estructura SharePoint: Azul Celeste

**Sitio Maestro:** `https://icconstructora.sharepoint.com/sites/GND/MA-AZULCELESTE`

Este documento detalla la estructura del proyecto Azul Celeste.

## 1. Subsitios Departamentales
Azul Celeste presenta una de las estructuras más robustas, replicando casi todos los departamentos del estándar.

| Departamento | URL Relativa | Propósito |
|---|---|---|
| **COMERCIAL** | `/COME` | Ventas y seguimiento de clientes. |
| **OBRA** | `/OBRA` | Avance físico y control de contratistas. |
| **PROYECTOS** | `/PROY` | Gestión estratégica. |
| **COORDINACIÓN TÉCNICA** | `/COOR` | Soporte técnico. |
| **ESTRUCTURACIÓN** | `/ESTR` | Viabilidad y modelos. |
| **ORIGINACIÓN** | `/ORIG` | Formalización de procesos. |
| **PUBLICIDAD** | `/PUBL` | Marketing y medios. |
