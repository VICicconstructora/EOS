# Estructura SharePoint: Bosque Central

**Sitio Maestro:** `https://icconstructora.sharepoint.com/sites/GND/Bu-BOS-CENTRAL`

Este documento detalla la estructura del proyecto Bosque Central dentro de la jerarquía de IC Constructora.

## 1. Subsitios Departamentales
Bosque Central utiliza una estructura de subsitios similar al estándar corporativo, con nombres abreviados.

| Departamento | URL Relativa | Propósito |
|---|---|---|
| **PROYECTOS** | `/PROY` | Gestión de proyectos y alta dirección. |
| **CARTERA** | `/CART` | Seguimiento de pagos y recaudos. |
| **COORDINACIÓN TÉCNICA** | `/COOR` | Gestión técnica y administrativa de obra. |

## 2. Bibliotecas de Documentos
A diferencia de otros proyectos, Bosque Central suele nombrar sus bibliotecas de forma explícita:
- `PROY BOSQUE CENTRAL` (en el subsitio /PROY)
- `CART BOSQUE CENTRAL` (en el subsitio /CART)
